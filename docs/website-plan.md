# 확정된 것

## 목적

검색으로 들어온 사람을 앱으로 보낸다. 동시에 광고 수익을 만든다.

앱은 홍보 수단이 마땅치 않다. 프랑스어·일본어까지 번역해 놓고도 알릴 길이 막막했다.
웹에서 SEO 로 사람을 모아 앱으로 흘리는 것이 이 사이트의 존재 이유다.

## 구조

```
parkinon.com/          → 콘텐츠 (주력, 검색 유입)
parkinon.com/app/…     → 기존 기록보기 (서브로 이전)
```

`/about` `/terms` `/privacy` `/delete-account` `/records` 는 **앱에서 눌러 넘어오는 진입점**이다.
콘텐츠 논의 대상이 아니다. 건드리지 않는다.

## 콘텐츠 — 4개 축 (확정)

| 축 | 내용 | 역할 |
|---|---|---|
| **1. 제도·지원** | 산정특례, 뇌병변 장애등록, 장기요양등급, 의료비·세금 공제, 보조기기 지원 | **SEO 본체** |
| **2. 생활 요령** | 아래 확장 목록 참조 | 검색 + 해외 확장 |
| **3. 도구** | 복약 시간표 만들기, 진료 전 질문 체크리스트, 기록 서식 | 재방문·앱 전환 |
| **4. 파킨온 소식** | 뉴스·연구 요약 | 양념 |

축 1 은 경쟁이 비어 있다. `파킨슨 산정특례` 검색 시 **10년 된 개인 블로그가 2위**였다.
⚠️ 이건 **경쟁 강도**만 본 것이고 **검색량은 확인된 적이 없다**(미결 1번과 연결).

## ⛔ 의학 정보는 다루지 않는다 (확정)

해외 사이트에 있고 우리에게 없는 축이 **둘** 있다. 조사해서 확인했고, **의도적으로 뺀다.**

- **질환 이해** — 증상, 원인, 진단, 유전, 감별진단
- **약과 치료** — 약 종류, 부작용, 복용 원칙, DBS 수술, 재활

### 왜 빼는가

1. **자리가 이미 없다** — `파킨슨병 약물치료` 검색 시 서울대·삼성서울·서울아산병원이 상위를
   독점한다. 신규 도메인이 병원을 밀어내는 것은 사실상 불가능하다.
2. **써도 안 읽힌다** — 구글은 의료 정보에 작성자 자격을 본다. 자격 표기가 없으면 순위가
   안 나온다. 품은 들고 유입은 없다.
3. **틀리면 사람이 다친다** — 약 용량·부작용·병용금기가 특히 그렇다. 우리 사용자는 60대
   이상이고 그대로 따라 할 수 있다.
4. **앱까지 같이 깎인다** — 웹에서 의학 정보가 틀리면 앱 신뢰도로 번진다. 앱이 본체다.

### 근거 — 해외 사이트는 전부 의사가 한다

**Parkinson's UK**: 파킨슨 전문 간호사 · 신경과 의사 · 노인의학 전문의 · 약사 · 물리치료사 ·
작업치료사 · 언어치료사 · 재무/법률 자문이 검수한다. **PIF TICK**(영국 유일 보건정보 품질 인증)
을 받고 제작 과정을 외부 감사받는다. 환자와 공동 제작하고 읽기 연령을 정기 측정한다. 그리고
**"AI 도구로 건강 정보를 쓰지 않는다. AI 를 의학적 근거의 출처로 절대 쓰지 않는다"** 고 명시해 뒀다.

Parkinson's Foundation · 마이클 J. 폭스 재단도 재단 소속 의료진이 있다.

**신경과 의사 섭외는 불가능하다는 것이 오너 판단이다(2026-08-01).**

### 참고 — 의사 없이 하는 곳의 방식

`parkinsons.org` 는 재단이 아닌 독립 운영자인데 의학 정보를 낸다. 이렇게 한다.

> 우리 콘텐츠는 아직 의사의 검수를 받지 않았다. 의료자문단이 구성되기 전까지 어떤 페이지에도
> "검수: ○○○" 표기를 달지 않는다. 전문가 자격을 지어내는 것보다 이렇게 밝히는 것이 정직하다고 믿는다.

「우리가 아닌 것」 페이지를 따로 두고, 모든 주장을 NINDS·MDS 지침·Cochrane 에 각주로 걸고,
모든 글에 최종 수정일을 붙이고, 오류 신고는 72시간 내 고친다.

**다만 이 도메인은 2002년 등록이다.** 24년 쌓인 신뢰를 업고 하는 것이라 우리에게 그대로
적용되지 않는다. 나중에 의사를 구하게 되면 이 방식을 참고한다.
