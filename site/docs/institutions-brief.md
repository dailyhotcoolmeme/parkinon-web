# 제도·지원 글 집필 지침 (2026-08-13)

해외판 제도·지원 글을 쓰는 **모든 배치가 이 문서를 먼저 읽는다.**

---

## 0. 대원칙 — 나라 기준으로 본다 (오너 지시 2026-08-13)

> "나라 기준으로 봐야지, 영어권 합쳐서 글 갯수를 보는게 말이 되냐고!
>  사용자가 자기 나라 기준을 볼거잖아."

영어판에 4편이 있어도 **미국 사용자에게는 미국 글 1편뿐**이었다. 그건 메뉴가 아니다.
**한 나라 사용자가 제도·지원 메뉴에 들어왔을 때, 그 나라 글만으로 메뉴가 성립해야 한다.**

이어지는 두 가지도 오너가 못 박았다.

1. **한국어판 5편을 정답으로 삼지 마라.** 한국 제도 구성은 한국 사정일 뿐이다.
   그 나라에 제도가 더 있으면 **글을 더 쓴다.**
2. **글은 많을수록, 촘촘할수록 좋다.** 편수를 아끼지 마라.

그러니 작업 순서는 이렇다.

```
그 나라 제도를 전수 조사한다  →  파킨슨병 환자·가족에게 쓸모 있는 것을 전부 추린다
                              →  필요한 만큼 글을 쓴다 (편수 제한 없음)
```

"몇 편 쓸까요"를 되묻지 마라. 조사해서 나온 만큼 쓴다.

## 1. 무엇을 다룰 것인가 — 훑어야 할 축

나라마다 이름과 구조가 다르다. 아래는 **빠뜨리기 쉬운 축의 목록**이지 정답표가 아니다.
그 나라에만 있는 제도가 있으면 당연히 추가한다.

- **소득 보전** — 장애 연금·수당, 상병 수당, 저소득 보조
- **의료비** — 공적 의료보험, 자기부담 경감, 약값 상한, 처방약 급여
- **돌봄·재가 서비스** — 방문 돌봄, 재가 지원, 시설, 가족 돌봄자 수당
- **보조기기·주택 개조** — 보행기·휠체어·손잡이 설치의 급여 여부
- **세제** — 의료비 공제, 장애 관련 세액공제
- **일** — 직장 배려 의무, 병가·휴직, 복직 지원, 장애인 고용
- **이동** — 장애인 주차, 대중교통 할인, 운전
- **가족** — 돌봄 휴가, 돌봄자 지원
- **지역·주(州)별 차이** — 연방제 나라는 이게 결정적이다. "어디서 찾는가"를 알려주는 글이 필요할 수 있다

## 2. 절대 규칙 — 확인한 것만 쓴다

제도 글에서 틀린 금액·요건은 **독자에게 실제 피해를 준다.**

- 공식 기관 페이지를 **실제로 열어** 확인하고, 확인한 것은 전부 `sources` 에 URL 을 넣는다
- 확인 못 한 것은 **지어내지 말고** 창구 안내로 일반화한다
- **"이 병이면 몇 급/얼마"라고 단정하지 마라** — 대개 증상 정도에 따른 개별 판정이다
- 금액·요율·소득 기준은 해마다 바뀐다 → `basisDate` 를 달고 재확인을 안내한다
  (미국 1월 COLA · 뉴질랜드 4월 1일 · 캐나다 1월·7월 · NDIS 비정기)
- 링크는 **HTTP 200 을 실제로 확인**한다. 404 인 채로 올리지 않는다

## 3. 글의 성격 — 제도 나열이 아니다

기존 글들이 잘한 지점이 이것이다. 제목을 보라.

- "The test List B does not answer: functional capacity"
- "The three-month rule catches people out"
- "The fast track most people never hear about"
- "Disability Tax Credit: apply even if you owe no tax"

**사람들이 실제로 걸려 넘어지는 지점**을 짚어야 글이다. 조사하면서
「이건 모르면 손해 본다」「이 순서로 안 하면 헛걸음한다」를 찾아내 그것을 절 제목으로 삼아라.

파킨슨병에 고유한 대목을 반드시 붙여라 — 증상 변동(온·오프), 서서히 진행한다는 점
(→ 처음엔 안 됐어도 나중에 다시 신청할 수 있는가가 결정적이다), 피로, 글씨·말하기.

## 4. 형식

**기준으로 삼을 글**: `src/content/articles/en/institutions/us-ssdi-disability-benefits.mdx`
(일본어는 `ja/institutions/nanbyou-medical-expense-subsidy.mdx`)

frontmatter 는 그 글을 그대로 따른다 — `basisDate`, `sources`(name+url), `contact`,
`hideAppPromo: true`, `section` 없음, `tag` 는 제도 이름. 스키마는 `src/content.config.ts`
가 정본이고 어기면 빌드가 실패한다.

본문 마지막 절은 **「If this applies to you」**(일본어는 「患者さんとご家族へ」)로 닫는다.

- `hero`/`thumbnail` 은 `src/assets/images/` 에 **실재하는 파일**. 인물 사진 금지.
  기존 제도 글이 쓴 것과 겹치지 않게 고른다.
- 용어집 앵커는 영어 `docs/glossary-anchor-map.txt`, 일본어 `docs/glossary-anchor-map.ja.txt`
  에 있는 것만 쓴다.
- 같은 나라의 다른 글끼리 서로 링크한다. **없는 글로 링크하면 404 다** — 대상 `.mdx` 가
  실재하는지 확인하라.

## 5. 언어별 용어

- **영어**: person-first. `patient`·`caregiver`·`sufferer`·`suffers from` 는 **금지어**다
  (`scripts/check-en-terms.mjs` 가 빌드를 막는다). `people with Parkinson's`, `care partner`.
  자세한 것은 `docs/en-style-guide.md`.
- **일본어**: 반대다. `患者さん` 이 정상이고 `ケアパートナー` 가 **금지어**다.
  `docs/ja-style-guide.md` 를 볼 것.

## 6. 끝내기 전 자가 점검

⚠️ `astro build` / `astro sync` 는 **실행하지 마라.** 배치 여러 개가 `.astro` 캐시와
`dist/` 를 공유해서 동시 빌드가 유령 오류를 냈다. 빌드는 오케스트레이터가 한 번에 한다.

```
cd /Users/ourmine/dev/parkinon-web/site
node scripts/check-en-terms.mjs        # 금지어·한국어 잔여
git status --short                     # 담당 파일 외 변경이 없어야 한다
```

그리고 손으로 확인한다 — 쓴 앵커가 앵커맵에 있는지, 내부 링크 대상 `.mdx` 가 실재하는지,
`hero`/`thumbnail` 파일이 실재하는지, 외부 링크가 HTTP 200 인지.

## 7. 중단에 대비할 것

세션 한도로 배치가 끊긴 적이 있다. **한 편을 끝낼 때마다 파일을 저장하라.**
조사를 다 모아놓고 몰아서 쓰지 말고, 한 편씩 조사 → 작성 → 저장으로 간다.
중간에 죽어도 완성된 글은 남는다.

## 8. 보고할 것

- 만든 파일 목록과 각 글이 다루는 제도
- **조사했지만 글로 쓰지 않은 제도와 그 이유** (다음 배치가 이어받을 수 있게)
- 확인한 출처 URL 과 확정한 사실을 표로
- 확인 못 해 일반화한 것
- 기존 글에서 새 글로 링크를 걸면 좋을 위치 (파일·절 이름)
