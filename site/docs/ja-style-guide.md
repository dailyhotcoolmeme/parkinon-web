# 일본어판 문체·용어 기준 (2026-08-12 확정)

영어판과 마찬가지로, 임의 판단 대신 **일본 파킨슨병 자료를 실제로 조사해** 정한 기준이다.
조사 대상: 武田薬品 パーキンソン病オンライン(환자·가족용 지원 페이지), 全国パーキンソン病友の会,
住友ファーマ·小野薬品 환자용 콘텐츠.

---

## ⚠️ 가장 중요한 것 — 영어 규칙을 일본어에 그대로 옮기면 안 된다

영어판은 person-first 원칙에 따라 `patient` 를 **금지**한다. 일본어는 다르다.

| 항목 | 일본어 | 비고 |
|---|---|---|
| 환자 지칭 | **`患者さん`** | 존중 표현으로 정상 사용된다. **피하지 말 것** |
| 돕는 가족 | **`ご家族`** (돌봄 맥락이면 `介護者`) | |
| **금지** | ~~`ケアパートナー`~~ | 일본 파킨슨 자료에 **쓰이지 않는다**. 武田 환자용 페이지에도 없다 |
| 병명 | **`パーキンソン病`** | |
| 앱 이름 | **`パーキンオン`** | 일본 App Store 등록명 |
| 문말 | **です・ます調** | 한국어판의 따뜻하고 평이한 어조에 맞춘다 |

실제 용례(武田 환자·가족용 페이지):
> 「患者さんとご家族の悩みはさまざまですが、病気の正しい知識を持つことで、不安は小さくなります。」
> 「ご家族だけで悩みや負担をかかえこまず、介護サービスや保健所の窓口に相談してみましょう。」

역할 라벨처럼 짧은 UI 문구에서는 `患者` 단독도 자연스럽다(`患者` / `介護者` 선택지 등).
앱 `ja.json` 이 이미 그 관행대로 되어 있다(`ご家族` 53 · `介護者` 24 · `患者さん` 93 · `ケアパートナー` 0).

## 한국어판 구조를 옮길 때

- `✅ 환자분께` → **`✅ 患者さんへ`**
- `🙋 보호자분께` → **`🙋 ご家族へ`**
- 이모지와 `###` 제목 수준은 그대로 유지한다.

## 한국 제도가 나오는 대목

일본어판 독자는 일본 거주자다. 한국 제도(건강보험·장기요양보험·산정특례·주민센터 등)는
**그대로 번역하면 안 된다.**

- 일본 제도로 바꿔 쓸 수 있는 것은 공식 출처를 확인해 다시 쓴다
  (예: 難病医療費助成制度 — `nanbyou.or.jp`, 介護保険, 障害年金).
- 확인하지 못한 것은 **일반적으로 서술**한다("お住まいの自治体の窓口でご確認ください").
- **확인 없이 일본 제도를 지어내지 말 것.** 제도·금액·자격 요건을 틀리게 쓰면 해가 된다.
- 한국 정부·보험공단 출처는 제거한다(일본 독자에게 근거가 되지 않는다).
