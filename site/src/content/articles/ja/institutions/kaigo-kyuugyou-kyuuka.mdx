ここまでの制度の多くは、<a href="/ja/institutions/shougai-nenkin/">障害年金</a>や
<a href="/ja/institutions/kaigo-hoken/">介護保険</a>のように、患者さんご本人のためのものでした。
これはご家族のための制度です。仕事を休んで介護に当たる配偶者・お子さんのための<b>介護休業</b>と
<b>介護休暇</b>を、2026年8月時点の厚生労働省の公式資料で確認して整理しました。

仕事と介護の両立は、通勤の途中や勤務時間の合間に急な用事が入るという点で、育児と似た難しさが
あります。

## 介護休業 — 通算93日、3回まで分けて取れます

要介護状態の家族を介護する労働者は、対象家族1人につき<b>通算93日</b>を上限に、
<b>3回まで分割</b>して休業できます。厚生労働省の定義では、要介護状態とは

> 負傷、疾病又は身体上若しくは精神上の障害により、<b>2週間以上の期間</b>にわたり常時介護を
> 必要とする状態

です。パーキンソン病そのものの診断だけでは足りず、実際にその状態にあることが要件です。
症状の進行で常時の介助が必要になった段階が目安になります。

<b>配偶者の父母（義父母）も含まれます。</b>お連れ合いがパーキンソン病のご両親を介護する場合も、
ご本人が申出をすれば休業を取得できます。

### 申請は2週間前までに

休業開始予定日の<b>2週間前まで</b>に、書面等でお勤め先に申し出ます。有期雇用の方は、休業開始から
93日を経過する日から6か月を経過する日までに契約が満了しないことが必要です。

## 介護休業給付金 — 賃金の67%

介護休業中は原則無給ですが、雇用保険から<Term brief="介護休業を取得した被保険者に、休業開始時賃金日額×支給日数×67％で計算される給付金です。休業開始前2年間に、賃金支払基礎日数が11日以上ある月が通算12か月以上あることが要件です。" href="/ja/lifestyle/glossary/#介護休業給付金">介護休業給付金</Term>が支給されます。

| 項目 | 内容 |
| --- | --- |
| 支給率 | 休業開始時賃金日額 × 支給日数 × <b>67%</b> |
| 主な要件 | 休業開始前2年間に、賃金支払基礎日数11日以上の月が<b>通算12か月以上</b> |
| 就労日数の制限 | 支給対象期間中の就労日数が<b>10日以下</b> |
| 支給の上限 | 対象家族1人につき<b>通算93日、3回まで</b>。同じ家族で要介護状態が変わっても再度は受けられません |
| 申請窓口 | ハローワーク |

<Callout text="育児休業給付とちがい、介護休業給付は<b>雇用保険の被保険者期間</b>が要件になります。転職して間もない方は、前職からの通算が認められる場合とそうでない場合があるので、申請前にハローワークで確認してください。" />

## 見落としやすい点 — 社会保険料は免除されません

<b>ここが育児休業と大きく違うところです。</b>育児休業中は健康保険料・厚生年金保険料が
被保険者・事業主とも免除されますが、<b>介護休業にはこの免除がありません。</b>日本年金機構が
公表している保険料免除の対象一覧には、産前産後休業と育児休業しか載っておらず、介護休業は
含まれていません。

<Callout text="つまり、介護休業給付金として賃金の67%を受け取っていても、<b>社会保険料は休業前と同じ満額</b>を払い続けることになります。給与から天引きできないため、多くの会社では休業から復帰したときにまとめて精算します。家計への影響は、育児休業のときよりも大きくなりがちです。休業を検討する際は、この保険料負担も含めて試算しておくことをおすすめします。" />

## 介護休暇 — 年5日・10日、時間単位でも

介護休業よりも短い単位で使えるのが<b>介護休暇</b>です。通院の付き添いや、ケアマネジャーとの
面談、急な体調変化への対応など、1日〜数時間だけ休みたいときに使います。

| 項目 | 内容 |
| --- | --- |
| 日数 | 対象家族が1人なら<b>年5日</b>、2人以上なら<b>年10日</b> |
| 取得単位 | <b>時間単位</b>でも取得可（2021年1月改正） |
| 給与 | 法律上は<b>無給が原則</b> — 有給にするかは会社の規定による |
| 申出方法 | 書面に限らず、<b>口頭での申出も可能</b> |

介護休業給付金のような<b>給付金の制度はありません。</b>会社が独自に有給扱いにしていない限り、
その日・その時間は無給です。

## 2025年4月の改正 — 「入社半年未満」を理由に断れなくなりました

厚生労働省の育児・介護休業法改正により、<b>令和7年（2025年）4月1日</b>から次が変わりました。

/>

<Callout text="改正前は、労使協定があれば「入社6か月未満の従業員には介護休暇を与えない」と会社が定めることができました。<b>今はそれができません。</b>除外できるのは「1週間の所定労働日数が2日以下」の場合だけです。もし会社の担当者が『入社してまだ半年経っていないから』と断ってきたら、この改正を伝えてください。" />

## こんなときは

| 状況 | どうするか |
| --- | --- |
| 配偶者の親（義父母）を介護しています | 対象になります。配偶者の父母も対象家族に含まれます |
| 入社してまだ3か月です。介護休暇を断られました | 2025年4月の改正で「入社6か月未満」を理由にした除外はできなくなりました。人事に確認してください |
| 介護休業給付金の67%だけで生活できるか心配です | 給付は67%でも社会保険料は満額のままかかります。休業前に、保険料の支払い方法（給与天引きできない分の精算時期）を会社に確認しておいてください |
| 通院の付き添いで半日だけ休みたいです | 介護休暇は時間単位で取得できます。介護休業（長期）を使うほどではない用事にはこちらが向いています |
| 93日をまとめて一度に使うべきか迷っています | 3回まで分割できます。症状の変化に合わせて、今すぐ全部使わずに残しておく選択もできます |
| 転職したばかりで介護休業給付金の対象か分かりません | 雇用保険の被保険者期間が要件になります。前職からの通算が認められるかはハローワークで確認してください |

## 患者さんとご家族へ

この制度はご本人ではなく、支える側のご家族のためのものです。介護休業は<b>長期の休みが必要に
なったとき</b>のため、介護休暇は<b>通院の付き添いなど短時間の用事</b>のためと、性格が違います。
両方を知っておくと、症状の波に合わせて使い分けられます。

社会保険料が免除されないという点は見落とされがちです。休業を決める前に、収入がどれだけ
減るか（給付67%からさらに保険料が引かれる）を具体的に計算しておくと、復帰後の家計の見通しが
立てやすくなります。
